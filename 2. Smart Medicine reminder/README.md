# Smart Medicine Reminder with Heartbeat Monitor

## What it does
A real-time embedded system that reminds patients to take 
medicine at scheduled times and monitors live BPM — 
designed for elderly independent-living use cases.

## Hardware (simulated)
- Microcontroller (8051)
- RTC module
- 16x2 LCD display
- Buzzer
- Pulse/heartbeat sensor

## Software
- Simulated in: Proteus 8
- Programmed in: Keil uVision (Embedded C)

## Validation
- Timing accuracy: ±1 second
- Alerts validated across 50+ test cycles
- Stable BPM readings across varying conditions
