# FPGA-Based Bank Queue Management System

## What it does
A hardware queue management system implemented on FPGA.
Manages token allocation, display, and queue flow 
entirely in hardware without a host CPU.

## Hardware
- FPGA board (Xilinx / Intel)
- 7-segment display
- Push buttons for input

## Software
- Language: Verilog HDL
- Tools: Vivado / Quartus Prime
- Simulation: ModelSim
