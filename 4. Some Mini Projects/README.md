# Mini Embedded & IoT Projects

A collection of small experiments and learning projects 
in embedded systems, IoT, and digital electronics.

## Includes
- Sensor interfacing (temperature, IR, ultrasonic)
- Arduino and ESP32 experiments
- Basic IoT communication (MQTT, I2C, SPI, UART)
- Digital logic implementations

## Tools used
Arduino IDE, Proteus, Keil, ESP32, Arduino Uno
